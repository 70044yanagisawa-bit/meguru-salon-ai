## 各社のいいところ

### STARNEST LIVE
- **不安にQ&A形式で先回りしている**：「はじめてでも大丈夫」の欄で、応募前の不安3つに答えている
  - 何を話せばいい？ → 好きなことを一緒に探していく
  - 仕事や学校と両立できる？ → あなたのペースで続けられる
  - ひとりで続けられる？ → 沢山の仲間に相談できる
- **費用の不安を数字で消している**：「登録・所属費 0円」「所属手数料 0円」をファーストビュー直下に置いている
- **公式パートナーのロゴを最初に出している**：DeNA Creator Links のロゴをヒーローに置き、信頼感を出している
- **サポートを時系列で並べている**：初期設定 → 活動方針の整理 → 配信アドバイス → 継続的な伴走
- **所属ライバーの声に属性を付けている**：「20代/女性」などの年代・性別を添えている。イラストの場合は「人物イラストはイメージです」と注記している
- **FAQが押さえどころを外していない**：「応募したら必ず所属しなければいけませんか？」「顔出しは必須ですか？」「地方に住んでいても応募できますか？」
- **CTAを1本にしている**：「LINEで応募・無料相談する」だけ。応募と相談を1つのボタンにまとめている

### MARU LIVE
- **所属ライバーを大量に、一言キャッチ付きで紹介している**：「昼はフルート奏者、夜は雑談居酒屋配信」など。実在感と事務所の雰囲気が一番伝わる
- **先輩ライバーの加入ストーリーを載せている**：どんなきっかけで加入し、今どうなったかを書いている
- **発信を続けている**：お知らせ欄とnote記事で、初心者向けのHow-to（初配信で何を話すか、事務所に入るべきか など）を更新している。検索から人を呼び込めている
- **無料オンライン相談会を開いている**：「ライバーなんでも相談室」
- **応募の窓口が2つある**：LINE とメール

### DAG
- **信頼情報をはっきり書いている**：会社所在地・設立日・顧問弁護士の名前まで載せている
- **入った後の安心策がある**：提携税理士を紹介している（確定申告の相談先）
- **「どんな人が向いている？」を一覧にしている**：話すのが好き、副業を探している、主婦、歌が得意、楽器が弾ける… と、読み手が自分ごとにしやすい
- **選考フローを具体的に書いている**：LINEで応募 → スタッフから連絡 → LINEのビデオ通話で面接 → 合格後にレクチャーと契約
- **他事務所に所属中の人への一言がある**：「許可を取ったうえでご応募ください」と明記している
- **FAQが現実的**：「毎日配信できないけど大丈夫？」「確定申告は必要？」「誰でも公式ライバーになれる？」（＝審査あり・約束はできない、と正直に答えている）
- **活躍の場を見せている**：ラジオ・CM・雑誌など、配信の外での実績
- ※収入実績（「6割以上が月20万円以上」）や補償制度は強い訴求だが、真似する場合は根拠データが必要

### 321
- **所属ライバー本人の一言を顔写真付きで並べている**：「何か困った時は相談にのってくれるマネージャーがいる」など、本人の言葉で語らせている
- **数字ページがある**：「数字で見る321」
- **今いるライバーへの動線がある**：月間トップライバーを紹介し、配信ルームへのリンクを付けている（実在の証明にもなる）
- **企業向けの窓口を分けている**：「ライバーを起用した案件のご相談」を受けている
- **コンテンツが充実している**：マネージャーインタビュー、コミック、オリジナルBGMなど
- **FAQが周辺までカバーしている**：「他のSNSのマネジメントは受けられますか？」「機材は必要？」

### LIVE Liebeaute
- **アプリ別にページを分けている**：TikTok / Pococha / BIGO LIVE / Palmu / IRIAM
- **ターゲット別の募集ページがある**：「ママさんライバー募集」
- **イベント・コンテストの告知ページがある**
- ※「業界屈指の還元率」のような最上級表現は、根拠がないと景品表示法上のリスクがあるので真似しない

## Invent on the way に取り入れたいこと（優先度順）

1. **所属ライバー・スタッフの実写と本人の言葉**（321・MARU）
   - AIっぽさを消すのに一番効く。名前（ニックネーム）＋一言キャッチ＋写真
   - コーチング事務所なので、「誰とどんな対話をして、次の配信で何が変わったか」の短いストーリーがあると強い
2. **「はじめての不安」に答えるQ&Aブロック**（STARNEST）
   - 何を話せばいい？／仕事と両立できる？／ひとりで続けられる？
   - 3つ目の答え「ライバー同士がコーチとして対話する」は、ブランドの強みそのもの
3. **FAQセクション**（全社共通）
   - 顔出しは必須？／地方でも大丈夫？／応募したら必ず所属？／毎日配信できなくても大丈夫？／機材は必要？／確定申告は？／未成年は？
   - 今のページは「よくある質問へ →」のリンクだけなので、主要な5〜7問はページ内に置く
4. **信頼情報**（DAG・STARNEST）
   - 会社概要（所在地・設立・代表者）を載せる
   - アプリの公式・公認エージェンシーなら、そのことをヒーロー付近に出す
   - 税理士など、相談先の提携があれば載せる
5. **選考・所属までの流れを具体的に**（DAG）
   - LINE → 面談（オンライン）→ 条件確認 → 契約 → 初回レクチャー。面談の所要時間や形式まで書く
6. **「こんな人に向いています」**（DAG）
   - Invent on the way らしく、「配信を自分の商品や仕事につなげたい人」「仲間と試しながら続けたい人」など、差別化ポイントで絞る
7. **発信・相談会**（MARU）
   - コラム／note、無料オンライン相談会。コーチングと相性がいい
8. **企業向け窓口**（321）
   - 「信頼を自分の商品や仕事につなげる」という事業紹介と合う

## 真似しないほうがいいこと
- 根拠のない収入実績や「業界No.1」「業界屈指」などの最上級表現（景品表示法のリスク）
- グラデーションやキラキラした装飾、イラストの人物（今回目指している「AIっぽくない」方向と逆）
- ニュース欄の放置（更新が止まると逆効果。運用できる範囲で）
