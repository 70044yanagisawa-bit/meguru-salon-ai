# 名刺（91 × 55mm 横）

サイト（`../public/`）と同じ設計言語で組んだ名刺です。HTMLとCSSだけで、印刷入稿用のPDFまで出せます。

```
card/index.html        名刺の中身（文字はここを直接編集）
card/card.css          デザイン（版面・色・書体）
card/card.js           入稿サイズの切り替えと印刷
card/入稿PDF/          書き出し済みのPDF（3サイズ）
```

> このフォルダは `public/` の外にあるので **サイトには公開されません**。連絡先が入るため、意図的に外に置いています。

---

## サイトとの合わせ方

| 要素 | サイト | 名刺 |
|---|---|---|
| 色 | 紙 `#f6f2ec` / 墨 `#1c1a17` / 柿渋 `#a84e2c` | 同じ |
| 書体 | 見出し＝Shippori Mincho、本文＝OSゴシック | 同じ |
| 縦組みラベル | ヒーロー右端の「美容室専門」1箇所だけ | 表の右端 1箇所だけ |
| 墨面への反転 | 進め方・CTAの1回だけ | 裏面の1回だけ |
| アクセント | 面には使わず、罫と番号と小さな印だけ | 表の罫の先端・裏のラベルだけ |
| 罫 | 左から伸びる1pxの罫 | 表の20mmの罫（先端4mmだけ柿渋） |

裏面はサイトのCTA（墨面に大きな文字1枚）をそのまま名刺サイズに落としたものです。
文言「美容室の“事務”を、閉店後に持ち帰らない。」はヒーローの見出しと揃えてあります。

## 1. 差し替えるところ

`index.html` の中の **〔 〕** が記入待ちです。

| 場所 | いまの表記 | 入れるもの |
|---|---|---|
| 表・左上 | `〔屋号を記入〕` | 屋号。無ければ `<p class="shop">` の行ごと削除 |
| 裏・TEL | `〔記入待ち〕` | 電話番号 |
| 裏・MAIL | `〔記入待ち〕` | 公開用メールアドレス |
| 裏・WEB | `〔記入待ち〕` | サイトの独自ドメイン |
| 裏・QR | `<div class="qr">` | サイトURLのQR画像に差し替え（下記） |

### QRの入れ方

正方形・余白なしのSVG（またはPNG 600px以上）を `card/qr.svg` として置き、
`index.html` の `<div class="qr">…</div>` を次に差し替えます。

```html
<img class="qr" src="qr.svg" width="15" height="15" alt="">
```

CSSは `.qr` がそのまま効くので、サイズ調整は不要です。
QRは墨面に載るため、**白地に黒ではなく「生成り地に墨」** で作ると馴染みます（読み取りに必要なコントラストは十分あります）。

## 3. 入稿する

`入稿PDF/` に3サイズ書き出し済みです。**通常は「塗り足し3mm」を使ってください。**

| ファイル | サイズ | 使うところ |
|---|---|---|
| `名刺_塗り足し3mm_97x61.pdf` | 97 × 61mm | ラクスル・プリントパック等のネット入稿（推奨） |
| `名刺_トンボ付き_103x67.pdf` | 103 × 67mm | トンボを求められたとき |
| `名刺_仕上がり91x55.pdf` | 91 × 55mm | 手元での確認・家庭用プリンタ |

1ページ目が表、2ページ目が裏です。

### 自分で書き出し直すとき

内容を直したら、ブラウザの印刷画面から作り直せます。

- 用紙サイズ … 上の表のmm（Chromeなら「カスタム」で指定）
- 倍率 … **100%**（「用紙に合わせる」にしない）
- 背景のグラフィック … **ON**（裏面の墨が出ません）
- 余白 … **なし**

コマンドで書き出すこともできます（Chromeが入っていれば）。

```bash
cd "/Users/yanagisawa/Desktop/ファイル/ツール/salon-ai-site" && python3 -m http.server 8799 &
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --no-pdf-header-footer \
  --print-to-pdf="card/入稿PDF/名刺_塗り足し3mm_97x61.pdf" \
  "http://localhost:8799/card/index.html?view=proof&mode=bleed"
```

## 4. 印刷の指定（発注時の目安）

| 項目 | おすすめ |
|---|---|
| 用紙 | マットコート、または上質系の白（紙の質感が出るもの） |
| 斤量 | 220〜260kg |
| 印刷 | 両面カラー |
| 加工 | なし（マットPPを掛けると墨面は締まりますが、紙の風合いは消えます） |

裏面は墨のベタなので、**マット系の紙のほうが指紋が目立ちません。**
色校正を取れる場合は、柿渋 `#a84e2c` の出方だけ確認すると安心です（CMYK変換で少し沈みます）。
